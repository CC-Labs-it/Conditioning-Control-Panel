Avalonia test plan (alpha / beta testers)

This is the hands-on checklist for the Linux app (the Avalonia head). Every area of avalonia-parity.html has a section here. You compare the Linux app with the Windows app ("WPF"). The WPF file:line after each step is the source line the expected behaviour comes from, so a developer can check a report quickly; you only need the Windows app itself. Paths are under ConditioningControlPanel/ unless they start with CCP.Core/ (Windows code that moved to the shared engine). Line numbers are the ones recorded in the ledger and may drift by a few lines.

How to report a result

One report per row id (a GitHub issue titled [test] <row id>: pass or [test] <row id>: fail), with:

  • Row id (the code name in the step or in the row list), and the step number if it has one.
  • Pass or fail.
  • What differed from Windows: text, order, timing, sound, a missing button, a crash. "Same as Windows" is a valid pass note.
  • Screenshot or short screen recording of the Linux app (and of Windows when they differ).
  • Your distro, desktop (KDE, GNOME, ...), X11 or Wayland, and the app version (Settings -> Updates).

A tester report is evidence that a developer adds to the ledger row, next to the automated test and the developers' own check of the running app; together they move a row to verified.

Before you start

  • Back up your settings folder first (~/.local/share/ConditioningControlPanel), or use a spare Linux user.
  • Use a test account for anything that spends points, tokens or lock time. Never a wallet you care about.
  • "Panic key" means the key in Settings (default Escape). "Rail" is the left navigation bar. "Tray" is the system tray icon menu.
  • Some areas are not on Linux yet (the ledger says missing). Check that nothing broken shows up instead, and report it if it does; there is nothing else to compare.

[SAFETY] steps (panic, Lockdown, stop and lock paths) are marked [SAFETY] developers re-check this before release. Please test them, but a tester pass alone does not clear them: the developers repeat them on the release build first.

General check (G), for every row in a "Rows" list below: open the screen named in the row (the Avalonia column of the ledger), click every button, toggle and tab on it, change the language once, and compare text, order, layout, sound and timing with the same screen on Windows. Report differences.
