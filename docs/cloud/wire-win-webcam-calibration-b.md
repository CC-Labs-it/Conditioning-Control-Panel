# Webcam calibration mouth checks and cursor trail

- Completes the two remainders of `win-webcam-calibration`; the row is `wired`. WPF is the behavior source; no code imported from parity/trunk (read-only trunk inspected at `a4ee52d40cd347d288dcf7fdaa8445b79f8e5038`).
- Extracts WPF's mouth aspect ratio and state machine to Core `MouthOpenDetector`, preserving three inner-lip chords, median of 3, the closed-frame baseline, sensitivity and speech thresholds, hysteresis, 250 ms held opening, 800 ms cooldown, and restart/face-loss rules. WPF keeps dispatch/diagnostic logging; Avalonia capture frames raise `OnMouthOpen` and both calibration prompts consume it. Queued events belong to their capture run; close unsubscribes gesture handlers immediately.
- Extracts WPF's bounded trail history to Core `GazeCursorTrail`; both heads call it. The calibration verify and bubble cursor draw the pink comet using geometry strokes on the window clock. Face loss clears it; countdown expiry, bubble exit, close and panic cancel the clock and subscriptions. Existing `PanicSurfaces` camera stop and its `SafetyCritical` coverage stop the tracker, whose state change closes calibration.
- Uses the production font builder in both touched headless fixtures, so a panic-first combined test run resolves Inter. Every existing assertion remains. Adds focused Core geometry/threshold/timing/history tests, calibration gesture/trail lifecycle tests, and a live fake-capture test of actual queued mouth-event delivery and stop-before-delivery cancellation. Tests use sandbox profiles, synthetic landmarks, and fake sources; no camera frames or user data are read or stored.
