# wire-svc-content-packs — active encrypted pack browser

- Library → Assets now lists active installed packs after local image/video folders, with WPF's pack → images/videos ordering, built-in display-name lookup and per-file blacklist counts. Refresh preserves the open virtual folder.
- Encrypted image thumbnails decode from streams through the existing four-slot thumbnail gate. Folder and file selections use `pack:<id>/<OriginalName>` keys and immediately affect active counts and playback pools; disabling a pack's files keeps the installation intact.
- The existing Preview action decrypts a pack file for MiniPlayer, deletes that temp on close, and registers `asset-preview` with panic so playback and decrypted previews end together. No new top-level surface was introduced.
- Core `PackAssetTree` owns tree construction and folder selection rules. The WPF reference head delegates both rules to the Core copy.
