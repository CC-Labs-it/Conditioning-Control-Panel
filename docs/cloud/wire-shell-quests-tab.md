# wire-shell-quests-tab

- Restore daily and weekly quest art from the definition's effective path: downloaded cache first, mod override next for bundled art, then mode-aware bundled resources. Reuse decoded images across cards and progress ticks; invalidate on a mod/mode switch.
- Move the built-in mode replacement rule into Core and delegate to it from both WPF and Avalonia. WPF keeps its existing URI/decode layer.
- Show the definition service's season title and refresh it when definitions update. Repaint the streak-fix balance while the tab is attached, then release event subscriptions on detach.
- Keep `shell-quests-tab` **stub**. Follow-up `wire-shell-quests-tab-b`: manual server-authoritative streak-fix spend/confirmation/cancel/in-flight handling, intake punch-card service/stamps (the WPF panel is currently disabled while the prize is TBD), perfect-week bonus seeding and missing producer calls for brain-drain minutes, completed sessions, received/issued remote commands, keyword triggers, and startup login streak. Streak shield and program verifier delegates are already seeded in this base; retain them.
- WPF references: `MainWindow/MainWindow.QuestsTab.cs` and `MainWindow/MainWindow.xaml.cs` (`GetModeAwareQuestImagePath`, `LoadQuestImage`). `parity/trunk` fetched read-only; no trunk code imported.
