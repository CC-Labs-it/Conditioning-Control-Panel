# Section tab strip: choose glow and press squish

- Choosing an existing section pill now uses the existing NavGlow one-shot ring in the section hue: Full animates, Reduced holds a static ring, Off omits it. The ring stops when its target detaches.
- Pointer press applies WPF's 0.97 squish and restores it on release, capture loss or click. Its scale sits before the independent hover scale, with 80 ms quadratic transitions; Off snaps to the same endpoints.
- Shared press values/endpoints live in CCP.Core InteractionPressMotion, and WPF MotionFx calls that copy.
- Added headless SectionStripChoosePressTests for actual pointer presses and clicks at all three motion levels, release outside cancelling navigation, right-clicks leaving the press scale alone, and glow removal on changing sections.
- No files imported from parity/trunk (read-only fetched tip a4ee52d40cd347d288dcf7fdaa8445b79f8e5038); adapted the repository's WPF SectionTabStrip.Fx.cs and MotionFx.cs and reused the base's NavGlow.
