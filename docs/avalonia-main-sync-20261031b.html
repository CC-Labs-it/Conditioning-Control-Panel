How a row gets closed

A needs-port row is closed when its lane's PR lands on port/7.2. Change the status cell to ported (#PR, sha) in that PR, never in a separate docs PR, so the ledger and the code land together. A row that turns out to need nothing is changed to n/a with the reason. ~/ccp-port/bin/ledger-check keeps the row count and numbering honest.
