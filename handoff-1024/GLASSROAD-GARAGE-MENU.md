# Garage menu and model accents, October 24

Owner requested an opaque, friendly loading screen, a single menu on the left of the kart ring with Racing Thoughts title art, animated Feedback bars, and a delegated pass for more moving details, lights and rotating spirals.

- Branch `codex/glassroad-garage-menu`, based on the complete liveness tip `0fe757bb7`. Parent review is #2800. Preview remains port 18892. Track, water, camera and server branches are untouched.
- `index.html` contains the loading cover before any module runs. `body[data-boot=loading]` hides the canvas, old card and HUD while all existing shader passes still run. Real progress drives the cover. `hud/loading.js` reveals only after two animation frames, then fades the opaque cover away. Do not remove warm-up as a shortcut: Firefox needs it before racing.
- `hud/garage.js` now has one title/menu block: Race, Race online, Customize EMI, Options, Controls. Existing actions and customization still use the original game flow. `render/garageLayout.js` shares screen-space positions between the menu, camera view offset, 3D arrows and accessible arrow buttons. Narrow phones use a compact lower menu.
- The invisible arrow buttons must retain `translate(-50%,-50%)` while pressed; the general button active transform otherwise moves the hit target during a click. The 3D mesh supplies the press animation.
- `render/feedbackMeter.js` moves all nine original white/coral bars around Y .264 in source space. An integrated phase accelerates during boost without a phase jump. It freezes at distance and restores the original mesh on disposal or motion off.
- `render/vehicleAccents.js` adds a shell-mounted themed rotor, counter-rotating Loom spiral core and softly lit ring to every vehicle. It reuses the existing `sky-spiral-open-mask`, four draws and at most 288 triangles per vehicle, no point lights or new textures. Exact static-shell triangle intersections place fittings; Pendulum and Velvet Lock use side mounts that clear their full ornament sweeps.
- New motion stays on the existing frame clock, calms under Gentle and restores rest for motion off. Existing rig, approved face atlas, outfit fits and private/public asset split remain intact.
- Validation: 907 tests; 13 Chrome interaction/loading/responsive checks; the same 13 on WebGPU; Firefox WebGL2 garage and race start. Opaque loading was captured during shader warm-up. Phone, tablet, desktop and customization frames were reviewed. Existing model clip/contact tests still pass.
